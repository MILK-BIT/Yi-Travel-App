## 支持功能
- 个人偏好设置——预填并保存用户的偏好
- 旅行规划——调用LLM根据用户输入地点与游览时间进行按天数划分的旅行规划并在地图上标明涉及地点位置
- 喜好的行程规划保存与修改——用户可以自己保存喜欢的旅行规划并可以进行手动修改
- 旅行规划分享——用户可以将保存后的行程规划分享给其他软件如微信、备忘录等
